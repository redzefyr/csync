# Traps — what is easy to step on

**Prefer the ones that fail silently** — the ones that raise no exception and
just quietly produce a wrong answer. Decisions and their reasons go in
[[decisions]].

⚠️ **A trap you can only meet inside one routine, type or interface goes in a
comment there** — this is read at session start, before the files are known.

One flat list of `##` entries. Copy
`~/.claude/skills/csync/templates/document/note-trap-entry.md`.
